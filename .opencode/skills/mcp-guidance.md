# MCP Tool Usage Guidance

When working on MovieliciousKMM, use these MCP tools as follows:

## Context7
Use `context7` when you need to look up official documentation for:
- Kotlin Multiplatform (`kotlinlang.org`)
- Ktor Client (`ktor.io`)
- Koin DI (`insert-koin.io`)
- SQLDelight (`cashapp.github.io/sqldelight`)
- Compose Multiplatform (`jetbrains.com/compose-multiplatform`)
- Jetpack Compose (`developer.android.com`)

Example: "use context7 to find the Ktor client multipart form data API"

## Grep by Vercel
Use `gh_grep` when you need real-world code examples for:
- expect/actual pattern in KMP projects
- Ktor client engine setup (OkHttp/Darwin)
- SQLDelight platform driver initialization
- Koin DI module registration in KMP
- CocoaPods integration with Kotlin Native

Example: "use gh_grep to find Koin KMP module examples on GitHub"

## Sentry
Keep disabled until Sentry is configured in the project.
